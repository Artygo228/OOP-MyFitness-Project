# MyFitness Gym Management System

This project is a comprehensive Java-based application developed as part of my Object-Oriented Programming (OOP) module. It demonstrates the full software development lifecycle, from UML architectural design to final implementation.

##  Overview
MyFitness is a local gym system designed to manage various membership types, staff records, and specialized bootcamp classes. The system ensures robust data handling and automates business logic such as age verification and discount calculations.

##  Features
- [cite_start]**Dynamic Membership Management:** Supports Standard, Student Saver, and Pay-As-You-Go models[cite: 50, 53, 60].
- [cite_start]**Automated Discounts:** Implementation of a 7% discount for multiple bootcamp enrollments via the `Discountable` interface[cite: 99].
- [cite_start]**Staff & Instructor Tracking:** Distinct hierarchies for full-time/part-time staff and fitness experts[cite: 48, 49].
- [cite_start]**Data Integrity:** Strict use of Encapsulation (private attributes) and Inheritance to ensure code reusability[cite: 71, 159].
